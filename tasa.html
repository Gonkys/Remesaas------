Llave de GitHub (configurar una sola vez)

Se pega una vez y queda guardada en este teléfono. Para crearla: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. En "Repository access" elegí Only select repositories y el repositorio de las remesas. En "Permissions → Repository permissions" poné Contents: Read and write. Copiá el token (empieza con github_pat_).
